# پروتوتایپ تعاملی کارما ۲٫۰

فایل `Karma-prototype-2.0.0.html` را دانلود کنید و با Chrome یا Edge باز کنید. نصب، سرور، حساب کاربری و اینترنت نیاز ندارد. فونت وزیرمتن (با مجوز OFL در `platform/backend/documents/fonts/OFL.txt`) و تصاویر منتخب در فایل قرار دارند.

کاتالوگ منتخب واقعی، جستجو، انتخاب کالا، اشخاص نمونه، پیش‌فاکتور، تأیید مشتری، تأمین، فاکتور، نمای ثبت دوطرفه، چاپ، دو واحد و خروجی JSON قابل امتحان‌اند. اسناد و قیمت‌ها آزمایشی‌اند؛ هیچ اتصال مالی یا Google Sheets وجود ندارد. داده‌ها در localStorage همین مرورگر نگهداری می‌شوند. با پاک‌کردن مرورگر ممکن است از بین بروند. قبل از بستن فایل، خروجی JSON بگیرید؛ واردکردن خروجی در این نمونه پیاده نشده است.

برای مشاهدهٔ آنلاین در GitHub روی فایل HTML کلیک نکنید؛ GitHub کد را نمایش می‌دهد. از **Download raw file** یا **Code → Download ZIP** استفاده کنید، ZIP را استخراج کنید و سپس فایل HTML را باز کنید.

## نسبت این نسخه با Google Sheets

بستهٔ GoogleSheets v1.3.0 مسیر قبلی مبتنی بر Apps Script است. بازنویسی `platform/` از Django/PostgreSQL استفاده می‌کند و با کپی‌کردن فایل‌ها داخل شیت اجرا نمی‌شود. این پروتوتایپ هم آداپتور شیت ندارد.

استفاده از ظاهر جدید با شیت ممکن است، ولی نیازمند پیاده‌سازی API در Apps Script، نگاشت شیت‌ها و ستون‌ها، کنترل دسترسی در سمت سرور، LockService برای نوشتن هم‌زمان، تولید شمارهٔ یکتا، اعتبارسنجی و ثبت تغییرات است. تضمین‌های تراکنش، قفل، تغییرناپذیری و حسابداری بک‌اند جدید خودکار به Google Sheets منتقل نمی‌شوند.

بازسازی فایل از داده‌های پالایش‌شدهٔ مخزن: `python prototype/build.py` در ریشهٔ مخزن.
